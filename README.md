# 다함께 꼬맨틀이란?

항공권 예약하려했는데! 매진이라 막막하신가요?

대한항공 항공권 빈좌석이 생기면 알려드려요

<p>
  <img src='https://imgur.com/QjjeOI3.png' width="77%"></img>
</p>

### 어떻게 쓰나요?

1. 소스 다운로드
2. .env 파일 만들어서 환경변수 입력
3. 필요한 라이브러리 설치
4. main.py에서 출발지, 목적지 코드에서 변경
5. main.py실행
6. GUI 나타나면 날짜 선택
7. 시작
8. 텔레그램 알림올 때 까지 기다리다가 칼결제한다

### 어떻게 알림을 받나요?

텔레그램 API로 받아볼 수 있어요.

환경변수에 텔레그램 API 토큰과 채팅방 ID만 넣어주면 돼요
